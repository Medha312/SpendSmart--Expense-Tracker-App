#  SpendSmart – Expense Tracker App

SpendSmart is a simple and efficient **expense tracking web application** that helps users manage daily expenses, analyze spending patterns, and maintain better control over their finances.  
Built using **React.js** and **Firebase**, it provides real-time updates and a clean, user-friendly interface.

---

##  Overview

The app allows users to:
- Log in or register securely using Firebase Authentication  
- Add, edit, or delete transactions (income or expenses)  
- View a running balance, total income, and total expense  
- See all transactions listed with timestamps  
- Use it seamlessly across all device sizes (responsive design)

SpendSmart keeps your financial data organized and accessible anywhere, anytime.

---

##  How to Use the Application

1. **Launch the app** – Open the SpendSmart web app in your browser.  
2. **Sign In / Sign Up** – Create a new account or log in using your existing credentials.  
3. **Add Transactions**  
   - Click **“Add Transaction”**.  
   - Enter a title (e.g., “Groceries”), amount, and select whether it’s *Income* or *Expense*.  
4. **View Dashboard**  
   - The top section displays your **total balance**, **income**, and **expense** in real-time.  
5. **Manage Transactions**  
   - Each transaction appears in a list below.  
   - Click **🗑️ Delete** to remove any entry.  
6. **Track Progress** – The totals automatically update whenever you add or remove entries.  

That’s it! SpendSmart handles everything else — calculations, updates, and storage in real-time.

---


SpendSmart follows a **modular React structure** with reusable components and Firebase integration.
